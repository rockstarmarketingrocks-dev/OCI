Site-Wide Technical Fixes

  • Single H1 everywhere: most pages have a content H1 and the theme title. Pick one approach and apply it site-wide.
  • Builder junk: base64 &nbsp; spacer blocks, nested pasted vc_row markup, data-slate-fragment / data-start / chat-UI class attributes. Strip them all.
  • City-page template problems: keyword anchors → empty /locations/, keyword anchors → retired goo.gl links, fixed 1000px map iframes, one stock image reused on 5 pages.
  • Images: redirect or noindex attachment pages (AIOSEO); rename junk media titles ("aaaa", "2323"); write real alt text; use WebP; never upscale 300px thumbnails.
  • Schema: one site-wide ProfessionalService/Organization entity (NAP below, hours, both phones, sameAs), then Service + BreadcrumbList per service and city page, BlogPosting on posts, FAQPage on /faq/ only.
  • Consistency: experience = "since 1996"; NAP = Rockstar Marketing, 385 Harbor Blvd, Suite 200, Destin, FL 32541 · (850) 542-3091 · toll-free (855) 545-3669 · info@rockstar-marketing.com · Mon–Fri 9–5; pricing tiers from post #33 ($1–2K / $2–4K / $4–8K+ per month).
  • Performance: LiteSpeed (WebP, lazy-load excluding the LCP image, critical CSS), one Home portfolio slider, lazy map and YouTube embeds.
