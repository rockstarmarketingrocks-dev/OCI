Summary. "Latest" is meant to be the blog page, but it's an empty published page: 0 words, no meta. WordPress isn't using it as the posts page either. In Settings → Reading, "Posts page" is unset (page_for_posts = 0), so /latest/ doesn't list any posts unless the theme template does it (verify live). As a result, the site's 6 blog posts have no crawlable index page linking to them. Those 6 posts also have no SEO title, no meta description and no focus keyphrase, and one has the slug /12280-2/. Each post is audited separately (pages 28–33). This page needs to become a real blog hub.

Method note: the live site can't be reached from the audit environment. Data comes from WordPress (connector) and AIOSEO. Verify live = check in the browser.

1. Priority Fix List

#PriorityAreaIssue → Fix
1P1Not the posts pageWP Admin → Settings → Reading → "Your homepage displays: A static page" → Homepage: Home · Posts page: Latest. WordPress will then render /latest/ as the blog archive (paginated list of posts) using the theme's blog template.
2P1Name / URL"Latest" is vague for users and search. Rename the page title to "Marketing Blog" (menu label "Blog"). Keep the slug /latest/ (simplest), or change it to /blog/ with a 301 from /latest/. /blog/ is clearer and what users expect; recommended only if /latest/ has no backlinks (check Semrush Backlinks).
3P1MetaEmpty. Set the SEO title and description (§2). AIOSEO → Search Appearance → Archives/Blog page controls these once it's the posts page.
4P1Menu & footerAdd "Blog" to the main menu and footer (verify live). Without it, the posts are only reachable through the sitemap.
5P2Intro textWordPress ignores the posts page's own content. Add an intro via the theme's blog options or AIOSEO's archive description: 2–3 sentences plus links to the service pages (§5).
6P2CategoriesThe 6 posts cover YouTube, Instagram, Amazon, AI marketing and SEO. Create 4 categories (SEO, Social Media, Video & YouTube, eCommerce & AI), assign them, and make sure "Uncategorized" isn't used.
7P2Blog → servicesEach post should link to its matching service page, and service pages should link to related posts ("Read: How to Start a YouTube Channel" on /video-marketing/, etc.). Details in the post audits.
8P2Pagination & archivesWith 6 posts, one page is enough. Make sure author, date and tag archives are noindex (AIOSEO) to avoid thin duplicates. Keep category archives indexable only once they have 3+ posts.
9P3Content cadenceLatest post date: check. Aim for 2 posts/month that support the money pages: Pensacola SEO, Pensacola web design, the FWB and SRB city topics, and AI search.
